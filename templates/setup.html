How to get cookies.txt

  1. Install a browser extension such as “Get cookies.txt LOCALLY” (Chrome/Firefox).
  2. Log in to youtube.com in that browser.
  3. Open the extension while on YouTube and export/download cookies.txt.
  4. Upload that file here.

Tip: use a private/incognito window logged into a throwaway account, export the cookies, then close the window so the session stays valid for the server.
